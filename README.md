# MiMo Bridge Monitor

Cross-chain bridge monitoring and transaction tracking. Built with **MiMo V2.5**.

## Features

- Multi-bridge monitoring (Stargate, Hop, Across, Synapse, Wormhole)
- Transaction status tracking with completion time
- Chain health monitoring with latency tracking
- Alert system for bridge failures
- SQLite persistence

## Usage

```bash
python monitor.py --dashboard
python monitor.py --bridges stargate hop
```
